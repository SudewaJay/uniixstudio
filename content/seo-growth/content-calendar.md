## Release checklist for each date

2. Request indexing for the URL in Google Search Console (URL Inspection → Request indexing).
3. Add the inbound links from older posts listed in `internal-linking-plan.md`, in the CMS admin.
4. Share on LinkedIn, Facebook and Instagram with the `og.jpg` card. If you add UTM parameters, use them only on external shares, never on internal links: `?utm_source=linkedin&utm_medium=social&utm_campaign=seo-growth-2026q4`.
